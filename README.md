# BioMind AI

An AI-powered biotechnology learning platform built with FastAPI, Python, React, and Groq API (Llama 3).  

## Features
- 🧠 Adaptive AI Tutor generating personalized lessons
- 📝 Quiz & Assessment Engine with instant AI feedback
- 🧪 Virtual Lab Simulator with decision-based experiments
- 🎯 Career Mentor with skill gap analysis
- 📊 Performance Analytics Dashboard

## Tech Stack
- Backend: FastAPI, Python, SQLAlchemy
- Frontend: React
- AI Integration: Groq API (Llama 3)
- Database: SQLite/MySQL/PostgreSQL
- Deployment: Local / Cloud
